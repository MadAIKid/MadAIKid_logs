一句话：要判断「仿 capsule 的多层投票 / 解码期多层共振」这个想法值不值得投入，本线按预注册判据统计了 S0→E-7 共七轮：S0 的均匀平均层间一致性零增量（5/5 组 CI 含 0 或为负）、E-2 路径级与 E-5a token 级判负、E-1 的 +2.9pt 其实只来自倒数第二层，最终只留下一个条件性结论——局部化信息注入剖面在控制 12 维熵轨迹后对答案正确性仍有 pooled +0.041 AUROC（CI [+0.008,+0.077]），但换 instruct 模型就掉到 +0.016（CI [−0.006,+0.043]）不显著，且全部是 teacher-forcing 后验特征、未做因果与在线验证。

0. 摘要

这条线要回答的不是「共振有没有理论依据」，而是「要不要为一个 capsule 式多层投票的设计继续投入 GPU」——所以第一轮就把判死阈值写死在出数之前。把「共振」拆成「谁投票 × 怎么量 × 兑现成什么」后，本线走完了七个可独立判死的档：S0（层间均匀平均）、E-1（MTP 跨视界）、E-2（路径级）、E-3/E-4（激发/信息注入剖面）、E-5a（token 级）、E-6（熵轨迹对照）、E-7（instruct 模型边界）。

结果是一条单调收窄的曲线：想法里的「多层聚合」在每一档都被证明不成立（E-1 全 32 层聚合 0.8594 < 单层 0.8595；零模型三次显示真实剖面比随机更平滑），但「深度剖面的标量形状含有答案正确性信息」这一残片活了下来，代价是把名字从 resonance 改成 localized information injection，并且必须承认它在强模型上不存在。

1. 问题与假设

决策问题：在单卡 32G、预算 <¥30 的前提下，是继续给「多层投票 / 解码期共振」这条线投算力，还是把结论收口成「一个条件性的序列级特征」并停手。这个问题被拆成三个可独立判死的子问题：

  1. 谁投票：MTP 的 K 个头 / 同一次前向的 L 层（logit lens）/ draft 树的 K 条路径；
  2. 共振怎么量：分布一致（KL / cosine / JSD）/ 隐藏态一致 / 路径级累积；
  3. 兑现成什么：省验证算力 / 提正确率 / 只做机理诊断。本轮拍板的是先做机理诊断，哪怕负结果；「计算量化」取算力归因/记账口径（每层花多少 FLOPs、产生多少可归因贡献），不是 int8/int4 数值量化。

预注册判死（写于 2026-11-16 23:2x，在 S0 出数之前）：

档 主要终点 判死条件
S0 控制 confidence 后的 ΔAUROC（5 折 GroupKFold + 1000× bootstrap） ΔAUC ≤ +0.01 或 95% CI 含 0 ⇒ 该构造无增量
S1 接受率 AUROC、接受长度 agreement 的 AUROC 不超 draft confidence +2pt ⇒ 判伪
S2 同 FLOPs 下的质量/吞吐 不优于「固定 draft 长度 + 精确验证」⇒ 判负

S0 之后判据被用户批评过一轮（「避免根据短期结果直接出死结论，当前实验比较简陋」），这条批评成立，于是 §10 补了「先找信息增量」协议：预注册最小可发布效应、每个构造单独检验不做共线特征一锅炖、结论分 SIGNAL / WEAK / NULL 三级，不再用「KILL 整条线」。E-1 起的每一档都按这个协议跑。

为什么怀疑已有做法（文献定位，2026-11-16 一次检索，33 条 arXiv id 逐个核对）：

零件 已被谁占 对本线的含义
跨层一致性当不确定性估计 2603.22299（单次前向、agreement patterns，分布内追平 probing、跨数据集迁移更好） 「一致性作为特征」已被做掉，只剩「是否提供 confidence 之外的增量」
解码期用多层 logits DoLa 2309.03883（late vs early 层对比，直接提升事实性） 「多层共振能提正确率」必须先打过 DoLa
draft 路径选择信号 EAGLE-2 2406.16858（draft confidence 校准良好、近似接受率）、SpecDec++ 2405.19715（acceptance head） 任何一致性信号要在同验证预算下打败一个几乎零成本的基线
一致性当停止/早退 2609.09989（预注册 3,520 条 consensus 规则零条通过）、2501.06240（routing 迭代只极化连接）、2605.29800（9 个不同家族 judge 只值 ≈2 票） 同源投票者的有效票数接近 1，「多层投票」的先验很低
上层表示冗余 2610.27711（任务信息集中在中上部 3–4 层，截掉 31% 层精度不变） 冗余层投票只是把同一误差再平均一遍

「capsule routing-by-agreement 用于 LLM 解码期」本次检索未命中——但这个位置空着的原因比空着本身更重要：它的三个前提（独立投票者、共识不饱和、共识≠置信度）在 LLM 上一个都不成立。

2.3 方法

层分布（logit lens）：对位置 tt 与第 ll 层残差流 ht(l)h_t^{(l)}，

pt(l)=softmax(Woutnorm(ht(l))),Gt=pt(L)p_t^{(l)} = \mathrm{softmax}\big(W_{\text{out}}\,\mathrm{norm}(h_t^{(l)})\big),\qquad G_t = p_t^{(L)}

S0 的四个共振量：atop1=1L∑l𝟏[arg⁡max⁡p(l)=arg⁡max⁡G]a_{top1}=\frac1L\sum_l \mathbf1[\arg\max p^{(l)}=\arg\max G]、acosa_{cos}（去均值 logits 的层间 cos 均值）、jsd_adj（相邻层 JSD 均值）、capsule 路由（r=3,β=4r=3,\beta=4，ul=p(l)u_l=p^{(l)}，sl=cos⁡(ul,u‾)s_l=\cos(u_l,\bar u)，w=softmax(βs)w=\mathrm{softmax}(\beta s)）、算力归因加权投票（cl=KL(p(l)∥p(l−1))c_l=\mathrm{KL}(p^{(l)}\|p^{(l-1)})，w=softmax(c/median(c))w=\mathrm{softmax}(c/\mathrm{median}(c))）、DoLa 对照。基线统一是 target-free 的三个置信度 {entropy, max, margin}；log_py、rank_y 用到了 target，只作诊断、不进基线。

E-1 的跨视界量：手工加载的 MTP 头在 tt 预测 t+1t{+}1；把「层 ll 的预测是否与 MTP 一致」构造成 (层 × 视界) 共振张量。标签（是否被接受）由最终层 argmax 定义，因此所有特征一律排除 l=Ll=L，否则标签泄漏。

E-3 起的激发/信息注入剖面：对每个生成 token 的预测状态位置（P+t−1，第一版错成 P+t，已修）：

  • 主测量 IGl=Hl−Hl+1IG_l = H_l - H_{l+1}（逐层 logit-lens 熵降）；
  • FFN 发放率 = down_proj 输入的正值比例 / 绝对值均值；
  • 残差更新 ∥hl+1−hl∥/∥hl∥\|h_{l+1}-h_l\|/\|h_l\|；
  • per-token z-score 后检局部峰（prominence>0.3、z>0.8），统计峰数/峰位/集中度；
  • 零模型：打乱层序后重算峰数分布。

统计：5 折 GroupKFold（按 chunk 分组，避免同块泄漏）+ logistic 回归 + 标准化；bootstrap 1,000 次（S0 按 chunk 重采样，答案级实验按题分组重采样）。

3.2 对照与消融

零模型（打乱层序）否掉了「多峰」：三次独立运行一致，观测峰数 1.55–1.60 vs 零模型 2.00–2.02，比值 0.77–0.80×。真实深层剖面比随机更平滑，结构是局部化/集中，不是分布式多兴奋点。这个对照比任何 AUROC 都更直接地否定了「多层共振」的字面主张。

标签泄漏审计：E-1 第一版特征包含了 l=Ll=L（而标签就是最终层 argmax），ΔAUC 从 +0.0287 虚高到 +0.0771（0.817→0.894），虚高 ≈2.7×。规则改成「特征一律排除 l=L」后重跑，才得到上表数字。

熵十分位分层（token 级）：控制熵后激发特征的层内 AUC 掉到 0.50–0.54，只有最低熵档 0.84——但那一档错误率仅 0.4%，是样本效应。控制置信度后没有留下信号。

独立实现复现（本地 Mac，Qwen2.5-0.5B / tinyshakespeare / 2,040 位置 / err_rate 71.0%）：基线 A（conf_entropy, conf_max, conf_margin）OOF AUROC 0.8066 → 加 8 个共振特征 B 0.8006，ΔAUC −0.0061（CI [−0.0118, −0.0003]），AURC 0.4651 → 0.4669。与 GPU 侧 S0 同向（无增量，且略差）。这套实现是独立代码路径（25 个 hidden state、自建 logit lens、torch.special.xlogy 对齐 scipy），掉进同一个结论说明不是某一侧的 bug。

单特征强度对照：E-7 上单个激发特征反而很高——ig_concentration 0.878、total_ig 0.865、mean_ig 0.758——但它们与熵/置信度高度共线，被 0.891 的强基线吸收，5 个一起加只有 +0.016。E-7 的正确率是 46.8%（同一 2wiki 任务上 base 侧只有 26.8–28%），所以这里的基线本来就更难打败。

3.3 反直觉 / 负结果

（1）mean_ig 就是熵的线性变换，这条代数事实改写了整条线的口径。 因为逐层熵降求和是 telescopes：∑lIGl=H0−HL\sum_l IG_l = H_0 - H_L，所以 mean_ig=(H0−HL)/L\text{mean\_ig} = (H_0-H_L)/L。实测 mean_ig 与最终层熵的相关系数是 −1.000。E-5a 里 mean_ig 单特征 AUC 0.842，与熵的 0.842 完全相同——这不是巧合，是恒等式。任何「信息注入」主张都必须控制熵/熵轨迹，否则只是在重复发现熵。E-6 就是这条事实的直接后果。

（2）token 级零增量（E-5a）：8,160 个 token，conf（熵+margin）AUC 0.853 → 加 9 个激发特征 0.852，ΔAUC −0.0009（CI [−0.0015, −0.0003]）。max_ig 0.632、mean_res 0.642、mean_act 0.616 全都不超出熵。机制主张在 token 粒度上不成立——这也说明 E-3/E-4 若成立，只能是序列聚合层面的东西。

（3）内容词比功能词更「不兴奋」，三次都反向：内容词峰 1.52–1.56 vs 功能词 1.67–1.69（p≤1e-8）。修正对齐前是「内容词更多」，说明该效应对对齐/口径极敏感，方向反直觉但稳定，暂不解释。

（4）E-1 的「省算力」承诺几乎兑现不了：信号集中在倒数 1–2 层，前缀验证显示省 4 层就掉回基线（m=24 → 0.818 vs conf 0.817）。所以「用 agreement 提前退出验证」的计算收益边际。

（5）E-2 的反直觉失败：路径级特征方向是对的（+0.050）但按特征挑轨迹反而比随机差（0.284 < 0.315）。这不是「信号弱」，是在 n 很小、正确率 32% 的设定下做 best-of-k 选择，选择本身引入了方差。

4. 结论与判定

判定：部分完成。 依据是预注册判据的逐条结算：S0 与 E-2 触发判负，E-3/E-4/E-6 在协议下判 SIGNAL，E-5a 判 NULL，E-7 停在显著性边界上（未做项与停手理由见 §6）。整条线按 mtp-resonance/REPORT.md 的结论收口，不再建议从「共振/投票」方向继续。

判据 阈值（预注册） 实测 结算
S0 ΔAUROC ≤ +0.01 或 CI 含 0 ⇒ 判死 5/5 组触发（最宽 −0.0244 [−0.0683,+0.0001]） ❌ 该构造判负
E-1 接受率增量 CI 下界 ≥ 2pt ΔAUPRC 或显著条件互信息 ΔAUC +2.9pt CI 不含 0，但 ΔAUPRC 仅 +0.0097（0.97pt）< 2pt ⚠️ 按 AUROC 显著、按自定 AUPRC 线未达标
E-2 重采样收益 同质量下重采样次数 ↓ ≥10% 未测到（best-of-k 0.284 vs 随机 0.315） ❌ 功效不足
E-3/E-4 增量 CI 下界 ≥ 预注册 MDE（SIGNAL） pooled +0.058 [+0.017,+0.091] ✅ SIGNAL
E-5a token 级 ΔAUC > +2pt 且 CI 不含 0 −0.0009 [−0.0015,−0.0003] ❌ NULL
E-6 强基线 控制熵轨迹后仍显著 +0.041 [+0.008,+0.077] ✅ SIGNAL（衰减 30%）
E-7 强模型 同 E-6 口径 +0.016 [−0.006,+0.043] ❌ 不显著

可写（支持的结论）

  1. 「多层投票 / 多层共振」作为机制不成立。 证据是三条独立线索：S0 的均匀平均 ≈ confidence 代理（5/5 组零增量）；E-1 的全 32 层聚合 0.8594 不如倒数第二层单层 0.8595；零模型三次显示真实剖面比随机更平滑（1.55–1.60 vs 2.00–2.02）。适用条件：Qwen 家族 base 模型、teacher-forcing、逐位置/逐序列统计。
  2. 跨视界（MTP）一致性对 draft 接受率有真实信息增量，但只是单层现象。 +0.0287 [+0.0205,+0.0368]（0.817→0.846），来源是倒数第二层；对 next-token 错误无增量（−0.0003 [−0.0012,+0.0006]）。
  3. 「局部化信息注入」是一个可复现、但条件性的序列级特征。 在 base 模型（正确率 26–28%、置信度基线弱）上，控制 12 维熵轨迹 + nll + margin + 长度后仍对答案正确性有 +4~5pt AUROC（pooled +0.041 [+0.008,+0.077]）；三次运行方向一致（+5~+9pt）。命名用 localized information injection，不叫 resonance。
  4. mean_ig ≡ 熵的线性变换（corr −1.000）是可以独立带走的测量学结论：任何「信息注入/惊讶下降」类的逐层读数，只要做层平均就会退化成 (H0−HL)/L(H_0-H_L)/L，必须先控制熵轨迹再谈增量。

不可写（诚实边界）

  1. 不能说「共振/多兴奋点」：零模型、单层对比、S0 三条证据都反向。
  2. 不能说「token 级激发标记了错误」：E-5a ΔAUC −0.0009，且熵十分位内层内 AUC 0.50–0.54。
  3. 不能说「在线可用」或「已证因果」：E-3/E-4/E-6 的特征全是 teacher-forcing 后验（需要整条前向），未做在线门控（E-5b），也未做层 ablation 的因果验证（E-8）。
  4. 不能说「在强模型上仍然有效」：E-7 的 +0.016 CI 含 0，单特征虽高（0.865–0.878）但被 0.891 的熵轨迹基线吸收。增量的本质是「当置信度本身不好用时补一点」，不是新的信息源。
  5. 不能说「路径级已被否证」：E-2 是功效不足（同题混合样本仅 12/150、CI 半宽 ±0.06），不是否证。
  6. 不能说「语义标签支持激发」：内容词效应三次反向，方向与直觉相反。

对后续决策的含义：从「共振」方向停手；E-5b（在线激发门控）不再建议做，因为可兑现价值依赖的增量在强模型上不存在；若要继续，只剩 E-8 因果消融（把相关变因果，¥10 量级）这一条有信息量的口子。

MTP 手工加载三坑（都会静默给出看似合理但错误的结果，值得单独成表）：

同样的权重、同样的掩码，准确率仍静默退化到 1.4% 走了 sdpa attention 路径 必须 eager attention + 4D bool 掩码（True=屏蔽）

# 一句话说清结论的标题

> **一句话**：要回答什么决策问题 → 做了什么 → 结论是什么（带数字） → 边界在哪（哪句话不能说）。

## 0. 摘要

3–5 句，要求「只读这段也能做决定」。

| 实验 | 问题 | 结果 | 判定 |
|---|---|---|---|
| X-a | … | … | ✅ |
| X-b | … | … | ❌ |

## 1. 问题与假设

- 这条线要回答的**决策问题**（"要不要继续投 X"，而不是"我们想研究 X"）。
- 假设与预注册判据（PASS / FAIL 阈值写在出数之前）。
- 为什么值得做，或为什么怀疑已有做法。

## 2. 实验设置

### 2.1 环境

硬件、显存、驱动、框架版本、是否 CPU/GPU；模型与数据规模。**写实测值**。

### 2.2 模型与数据

checkpoint 名称、参数量、数据来源与行数、下载/校验方式（字节数、md5）。

### 2.3 方法

读数/探针/指标定义（公式用 `$...$`）、对照组、零模型、bootstrap 次数、seed 数。

## 3. 结果

### 3.1 主结果

**必须有表**：配置 / 指标 / 数值 / 95% CI / 判定。数字保留原始精度。

### 3.2 对照与消融

零模型、label shuffle、随机特征、容量控制——证明指标没有被高估。

### 3.3 反直觉 / 负结果

哪些子假设被推翻、哪些数字与预期相反。

## 4. 结论与判定

- **判定**：`完成 / 部分完成 / 判负 / 中止`，以及依据（阈值 vs 实测）。
- **可写（支持的结论）**：2–4 条，每条带数字与适用条件。
- **不可写（诚实边界）**：2–4 条，明确哪些话不能据此说。
- 对后续决策的含义：继续 / 改方向 / 停。

未跑的实验、功效不足的对照、被中止的原因（实例失联、余额、硬件不足）。
